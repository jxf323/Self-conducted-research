After the summer camp led by UChicago, I was intended to publish a paper. The project I did for this paper is that I analyzed dark web data traffic package, and using my proposed method of training models, I improved the prediction accuracy to nearly full mark.

These pictures compare between original default method of machine learning and my proposed method. There are two labels for my dataset. The first picture focuses on the first label, and the second picture focuses on the second label, while the third picture focuses on both labels, treating both label as a whole. Each interval between two integers denotes a specific model. For each model, 10 experiments were conducted. My method is denoted in blue, and default model is denoted in green, and the difference of performance is denoted in yellow. The explanation of these charts is that if the dot is closer to the poles, the accuracy is higher. That is to say, if the yellow is above equilibrium (y coordinates of 0), my method performs better. As we can see, yellow dots mostly stay above ground, meaning that my method has positive effect on the accuracy of prediction of the model.
